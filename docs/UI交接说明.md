# 宠智灵 APP 3.0 · 爬宠摄像头 UI 交接说明

版本：接入原型 v1 · 2026-09-23

## 设计基线

参考：[APP 3.0 首页交互原型](https://czy666-cc.github.io/czl-app3-prototype/home.html)。已读取其首页框架、颜色、卡片及底部导航样式。此次重点是爬宠摄像头接入，AI 管家、生活、趣养和账号不重新设计；管家不展开对话流程，社区流程不展开。

全局导航固定为「首页 / 生活 / 管家 / 趣养 / 我的」。首页的设备卡为主要入口；消息和异常提醒为事件入口；我的汇总宠物档案与设备订阅。进入摄像头和二级详情后隐藏全局底栏。由报告进入管家时，保留返回按钮和来源上下文，同时仍可使用管家所属的全局底栏。

## 层级与组件

### 首页和设备卡

重要提醒置于首页上部；已读仅清除未读标记，待关注事件继续保留。设备卡采用双列布局，宽高比约 1.24:1：顶部方形缩略图、设备名和 WIFI 在线标签；下方两个浅底指标格展示「爬宠品种」与「活动时长」。品种读取关联宠物档案，不需要 AI 会员；长品种名称单行省略，完整名称可在宠物档案查看。活动时长读取当前设备、当前关联宠物的当日行为报告（分钟），按 AI 会员权益展示，与智能养护保持一致。卡片不展示预览时间和异常摘要，也不额外占行展示宠物名称；关联宠物仍可在设备内查看。指标不依赖环境配件。活动时长在未关联、未订阅、分析中、数据不足时分别显示待关联、未开通、分析中、待积累，不将缺失值显示为 0；离线可保留已有历史识别结果，卡片只标记离线，最后在线时间在设备内展示；隐私模式覆盖缩略图。多设备可滚动，每台卡片可独立进入。

### 视频直播

视频约 1.8:1，顶部在线及可切换画质，底部时间；参考修改前的 index.html，下方四个工具为全屏、截图、录像、分享。分享打开现有设备共享弹层。本地回放、云回放、相册、隐私模式以两行两列独立小卡片展示；云回放未开通时标明需开通当前设备会员，点击进入开通引导；夜视模式已移除。截图后视频底部显示缩略图、保存提示和「进入相册」按钮，点击可查看已保存记录。录制时按钮文字变为「结束录像」；完成或离开实时页时生成相册记录。全屏使用画布内黑色大图预览模拟，带明确关闭入口。

实时画面仅在在线且非隐私模式时展示。离线/隐私不能仅依赖文字标记，必须遮挡画面并禁用实时操作。已有历史报告、云录像、相册仍可按权益查看。

### 智能养护

固定顺序：饮食分析 → 活动分析（含活动区域热力图）→ 蜕皮检测 → AI 状态解读 → 健康评估 → 异常疾病风险识别 → AI 健康解读。饮食板块展示最近两次识别时间并提供查看详情。活动时长与热力图合并展示。健康首页隐藏三个子指数，明确提供查看健康报告；报告内保留维度和雷达图。疾病风险只展示，不可点击。综合状态解读仅使用进食、饮水和活动，不包含晒背。

行为详情保留原版各自的统计、习性、AI 分析和识别记录；蜕皮展示周期与时间轴。进食、活动保留可操作的周日期选择，健康详情保留原版近 7 日趋势与维度雷达图。所有评分、风险、习性分析和日期均为原版演示样例，不代表正式算法输出。

本期已移除环境监测：看护、智能养护、设备信息及订阅说明均不展示环境配件、温湿度或环境告警；场景演示同步移除相关入口。

### 弹层和表单

使用底部 sheet：设备切换、名称、档案关联、新建档案、共享、网络、固件、设备信息、移除确认、开通确认。标题、关闭按钮固定在内容起点；弹层最大占画布 88%，内容可滚动。弹层打开时背景不可交互，Tab 在弹层内循环，Escape 关闭。

名称输入 30 字、宠物名 20 字、物种 30 字；空白不可提交。设备标题单行省略，列表和详情可换行；移除确认中显示完整设备名称，避免误删。配网与邀请输入错误在表单内说明，不能只弹短 Toast。

## 视觉对齐原则

摄像头内部参考旧版的内容与功能入口组织，保持当前 APP 3.0 的 UI 和配色：白色圆角卡片、蓝色主按钮、现有字体、背景与顶部双栏目导航。没有恢复旧版底部摄像头导航、彩色渐变按钮或设备控制。

## 必需设计状态

| 场景 | UI 结果 |
|---|---|
| 无设备 | 首页空态 + 添加入口 |
| 未关联宠物 | 看护可用；AI 引导关联或创建 |
| 未订阅 | 全部养护板块及详情显示示例数据，保留设备会员入口；不解锁真实报告或云回放 |
| 分析中 / 数据不足 | 分别使用“正在分析”和“还没有足够的数据”；不画虚构数值 |
| 未检测到蜕皮 | 不存在对应证据片段，仍保留观察建议 |
| 离线 | 停止实时操作；存储卡不可读；云历史可访问 |
| 隐私 | 画面遮挡，拥有者在线可关闭；共享成员无操作权限 |
| 共享成员 | 查看内容；管理表单禁用；禁止截图录像、关联变更和开通 |
| 无 SD / 无录像 / 回放失败 | 各自独立文案；可切换来源/日期或重试 |
| 绑定失败 / 超时 / 已被绑定 | 原因与恢复入口；不生成半成品设备 |

## 响应式与交付注意

桌面以 390 px 手机外框展示；高度适应当前窗口。620 px 以下改为整屏应用，演示区移到手机画布下方。安全区通过 env(safe-area-inset-*) 预留，表单与 sheet 保持滚动；真正软键盘的遮挡和原生导航手势仍需目标手机验收。

UI 出图至少包含：首页、看护、陪伴、行为详情、事件详情、回放、设置、订阅、添加 5 步，以及上表异常态。请不要把左右说明面板、场景按钮、演示结果选择器当作正式 APP 界面。

未订阅示例在页首及各板块标记，详情继续标记。分析中、数据不足保留全部板块并逐项显示状态，无有效数据时不展示正常结论、健康分或热力颜色。有效的部分结果仍展示，尚无详情的入口禁用。

饮食分析、活动分析及蜕皮检测使用统一标题栏和右上角详情入口。蜕皮检测在标题下方以浅底区域展示状态及说明，取消横向图标卡布局。

智能养护分成两个同级浅蓝分组：今日状态包含饮食、活动、蜕皮及 AI 状态解读；健康评估包含 AI 多维健康分析、异常疾病风险识别及 AI 健康解读。两组的 AI 解读均位于组内末尾，使用略深底色作为总结。

当前状态统一：已移除“分析中”场景及识别状态文案，统一使用“数据不足”。缺失数值显示 —，热力图保持中性占位，健康和风险区域不显示正常结论。部分结果可用场景仍保留。

事件缩略图显示播放图标；饮食与活动详情内点击后以当前页居中悬浮弹层展示对应宠物、日期、时间和事件标题。播放器提供暂停、播放、进度拖动及结束重播，关闭后恢复原滚动位置及焦点。原型明确标注静态示例画面与模拟播放。

事件视频弹层现简化为页面中央的播放器，仅保留画面、播放控制、进度及右上角关闭按钮；不展示标题、事件信息或说明文字。事件上下文保留在无障碍名称中，原型仍使用静态示例画面模拟播放。


摄像头直播操作栏为全屏、截图、录像、画质；画质按钮上方浮层沿用高清／标清演示选项，选择后自动收起，点击外部或按 Escape 可关闭，画面角标只显示当前值，实际档位需由视频能力确定。离线、隐私状态禁用画质操作。摄像头内已移除分享、共享设备入口及手机号邀请流程，家庭共享由 APP 原有家庭管理承接，本原型不新增实现。

“我的”已按 APP 参考页绘制为静态展示：个人资料、宠物档案／设备管理双卡、活动横幅、常用功能和更多功能。沿用当前蓝白视觉；页面内的铃铛、卡片、图标及横幅均不提供跳转，底部全局导航仍正常使用。已复核 320px 和 390px 布局。
