# 宠智灵 APP 3.0 · 爬宠摄像头开发交接说明

版本：接入原型 v1 · 2026-09-23

## 实现入口与边界

根目录 `index.html` 为离线单文件交付，`script.js` 为状态与交互源文件，`styles.css` 为视觉源文件。`prototype/build.py` 从 shell、脚本、样式及本地图片生成 HTML；禁止仅改内嵌脚本。原型无生产 API，不用此 JavaScript 实现真实认证、支付或设备权限。

APP 保留统一登录、宠物档案、家庭、消息和管家体系。本期摄像头两个栏目：视频直播、智能养护；设备控制不接入。AI 管家、生活和趣养只提供明确的接入边界与参考入口；不实现管家对话或社区流程。

## 数据对象与页面需求

下表是视图所需数据，不是正式 API 协议。标识应由现有服务提供，不以原型时间戳 ID 直接上线。

| 对象 | 原型字段 | 正式对接要求 |
|---|---|---|
| Device | id, name, petId, online, lastSeen, role, network, firmware, sd | 设备服务提供身份、在线状态、能力及角色；离线不能显示实时数据 |
| Subscription | 每设备 subscription: active/inactive | 计费服务提供权益项、有效期及适用设备；原型仅两态，开通不影响其他设备 |
| Pet | id, name, species | 复用 APP 宠物 ID；一台摄像头首版一只宠物 |
| Event | id, deviceId, petId, type, title, time, read, resolved, detail, evidence | 同一事件多入口共用 ID；已读是用户消息状态，解决状态是事件状态 |
| Report | id, deviceId, petId, date, food, water, activity, region, molt, healthScore, risk, states | 保存生成时宠物归属、实际分析窗口、算法状态和证据引用，不反查当前 petId 作为历史身份 |
| Media | id, kind, time, duration | 原型只保存示例记录；正式接媒体文件/相册服务与权限 |
| Share | id, phone, status | 模拟 pending/accepted；正式邀请复用家庭服务，并在服务端校验授权 |
| 管家接入上下文 | contextKey, deviceId, petId, reportId/eventId, date, title, summary | 仅展示待带入 APP 3.0 的记录，不实现会话和回复 |

正式能力清单需覆盖实时流、SD、云回放、共享权限。夜视已从原型移除，128 GB 存储卡为示例，不是硬件承诺。

### 跨模块跳转上下文

原型维护 `view + stack`：page、deviceId、section、date、scroll；事件附 eventId，报告附 reportId/kind，回放附 source/playDate/segment。进入子页先保存来源快照，返回恢复设备、栏目、日期和滚动位置。行为详情使用 reportDate 选择日期，按原宠物和设备查询对应报告；有记录时同步更新 reportId，确保证据和管家上下文使用所选记录；无记录时显示空态并隐藏分析操作。切换全局栏目清空当前局部返回栈。

从事件进入管家，携带 deviceId、deviceName、petId、petName、reportId 或 eventId、title、date、summary、contextKey。历史报告使用其原 petId；当前原型仅展示接入上下文，正式对话和会话恢复沿用 APP 3.0。不得仅携带一段文案而丢失记录标识。

正式路由沿用 APP 的已有路由设施；这里不虚构 URL 或接口路径。消息跨设备跳转先定位 deviceId，再定位事件/片段。

## 状态规则与权限

| 功能 | 拥有者 | 共享成员 | 离线 / 隐私 / 权益限制 |
|---|---|---|---|
| 直播 / 全屏 | 可看 | 可看 | 离线或隐私时遮挡 |
| 截图 / 录像 | 可操作 | 不可操作 | 离线或隐私时禁用 |
| 隐私 | 可改 | 只读 | 离线不能发实时指令 |
| 存储卡回放 | 可看 | 可看 | 需设备在线、有卡；不要求订阅 |
| 云回放 / AI 历史 | 可看 | 继承设备权益查看 | 需该设备有效订阅；离线保留历史访问 |
| 命名 / 关联 / 重新配网 / 共享 | 可管理 | 只读 | 正式请求需服务端校验 |
| 订阅开通 | 可模拟开通 | 不能开通 | 只影响购买的设备 |
| 移除设备 | 解除拥有关系 | 停止接收共享 | 原型均移出本地列表；生产语义不同 |

原型权限同时在操作处理函数中检查，不只依靠按钮禁用；生产权限必须由后端/设备服务验证。

### 添加与重新配网

选择设备 → 准备与设备码 → Wi-Fi → 连接中 → 命名 → 关联/跳过 → 新设备看护。

连接失败/超时/已绑定返回 Wi-Fi 步骤并说明原因，保留网络名称，密码清空；重试不产生新设备。取消连接取消计时器；取消整个流程丢弃草稿。只有关联确认或稍后关联时，才将新设备写入演示库。新设备默认未订阅、数据不足。

重新配网使用已有设备 ID；成功更新网络和名称，返回设置，不创建副本。真实配网协议、频段、设备发现、扫码、已绑定判定由 SDK/服务提供；输入的模拟设备码不代表真实硬件校验。

Wi-Fi 密码仅存在提交前的输入框中，不进入 wizard、db 或 localStorage。原型不发送网络请求。

### AI 分析

未关联保留关联引导；已关联未订阅使用独立示例对象，不写入报告。已订阅按每个模块 states（ready/insufficient）及数据是否存在判断。无显式状态时兼容原设备 analysis；缺少新增字段显示数据不足，不补造旧数据。本期不展示环境监测、环境配件或环境告警。会员开通仅更新 subscription，不重置事件或报告。

原型“未检测到蜕皮”是识别结果，不能推断没有蜕皮。综合健康评分与疾病风险已按原版恢复，均为固定演示样例，不定义正式算法。环境适应维度随环境监测移除。正式分析服务必须明确支持物种、最小观察窗口、指标定义、缺失原因及证据关联。

更换宠物关联会将当前分析标记为数据不足，防止旧报告冒充新宠物结论；旧报告列表继续保留原宠物姓名。原型日期固定为 2026-09-23，历史有 2026-09-22；其他日期显示无数据。

### 事件与消息

打开事件详情标记 read=true；“全部已读”只更新 read，不修改 resolved。首页、消息、摄像头共享同一记录。首页提醒继续展示未解除事件，避免用户把已读误当处理完成。

原型“记录为已处理”将 resolved=true 以演示行为事件处理闭环。环境监测已移除；旧版 localStorage 中残留的 environment 类型事件会被展示层过滤，不出现在首页、消息、近期事件或回放标记中。

### 播放与媒体

存储卡依赖在线与 SD；云端依赖设备订阅，不依赖实时在线。隐私只遮挡实时画面，已有历史仍可查看。日期、来源、分段和倍速均可切换；失败可重试，无录像不给播放按钮。

录制再次点击结束，或离开实时页时自动结束，生成相册记录；切设备先结束旧设备录制。截图立即记录。原型全屏/录像均用示例图片，不提供真实播放器或文件导出。

## 本地存储与兼容

使用 localStorage key `czl-app3-camera-v1`，版本 1。刷新回首页并恢复数据；不恢复连接中流程。JSON 不可解析或版本不符时初始化演示数据；浏览器禁止存储则保持当前会话并显示说明。场景切换清空并重建示例库，方便评审复现。

不存在网络同步、跨账号隔离、跨浏览器同步、付款记录或真实消息发送。不要复用此前独立摄像头原型的账号模型。

## 对接前必须确认

| 负责人 | 需确认的输入 | 当前原型处理 |
|---|---|---|
| 硬件/SDK | 配网协议、频段、蓝牙发现、SD与流协议、断连/隐私指令回执 | 明确演示；未声明蓝牙可用；无实际指令 |
| 算法 | 支持物种、识别窗口、质量状态、阈值、证据片段及数据更新 | 使用原版固定健康与行为样例，缺失状态独立 |
| 商业化 | 套餐价格、期限、云存储天数、到期后的历史可读策略 | 价格/存储时长待确认；默认有效订阅才可读 AI 历史与云录像 |
| APP 平台 | 现有登录、家庭服务、消息类型、管家上下文、深链及通知权限 | 复用框架，原型仅模拟 |
| 产品/数据 | 解绑后的数据保留、共享取消的历史权限、隐私模式对云端新录像的影响 | 原型移除本地记录；正式政策另确认 |

这些事项不阻止 UI 按已定义状态出图，但未确认前不能据演示数值完成生产接入。

## 验收与埋点建议

自动化覆盖：首页与二级导航、回退恢复、消息已读、会员隔离、截图录像、共享权限、分析中/不足、重新关联、绑定三类失败及重试、取消、重新配网、最后设备移除、回放空/错态、输入转义和无脚本异常。

建议正式集成记录：device_open、bind_result、stream_result、playback_result、report_open、ask_butler、subscription_result；关联 deviceId、source、result/errorCode，不记录 Wi-Fi 密码或对话正文。原型不发送埋点。

UI 真机验收包括 320/390/430 宽度、长名称、底部安全区、软键盘与 sheet、返回手势、横竖屏切换。视频 SDK、支付、固件与推送不在本地原型验证范围内。

## 原版内容恢复

`prototype/original-camera.json` 保存从 `outputs/pre-app3-backup/index.html` 提取的行为详情和健康内容。构建时嵌入图片与模板，仍可单文件离线打开；不要仅改生成后的 HTML。健康和行为分析受设备 AI 权益、关联与数据状态约束。新版移除摄像头中的摘要、待关注事件、历史列表入口、通用行为趋势及报告问管家入口。原宠物报告归属仍保存在数据中。

智能养护的示例详情携带 sample、petId、sampleDate、deviceId，返回恢复来源滚动位置；示例权益不影响云回放。首页进食/饮水时间与详情读取同一 report。模块包含 food、water、activity、region、molt、health、risk，综合解读等待相应依赖就绪。疾病风险首页无跳转，健康报告保留内部维度。

旧设备 analysis 或模块 states 的 pending 值仅作为兼容输入，展示层统一归为 insufficient；不改动共享邀请的 pending（待接受）状态。

事件片段弹层携带当前设备、宠物、日期、事件时间、标题和示例标识，不进行页面跳转。关闭时清理播放计时器并恢复焦点；背景不可交互，支持 Escape 关闭。当前仅用静态画面模拟 15 秒进度，未接入视频文件；真实实现需接入对应事件片段及播放器服务。示例播放不改变订阅权益。


摄像头直播操作栏为全屏、截图、录像、画质；画质按钮上方浮层沿用高清／标清演示选项，选择后自动收起，点击外部或按 Escape 可关闭，画面角标只显示当前值，实际档位需由视频能力确定。离线、隐私状态禁用画质操作。摄像头内已移除分享、共享设备入口及手机号邀请流程，家庭共享由 APP 原有家庭管理承接，本原型不新增实现。
